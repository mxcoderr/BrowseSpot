# BrowseSpot
BrowseSpot - легковесная поисковая система, написанная на языке Rust.

**Преимущества**:

1. Не метапоисковик

Полноценная поисковая система с собственной базой данных, а не просто метапоиск (в отличие от SearxNG и многих других систем я до сих пор не понимаю смысла метапоисковиков - они лишь выдают ссылки на другие поисковые системы, по сути, занимаясь их рекламой).

2. Без ИИ - предсказуемый и прозрачный поиск

Без использования ИИ и без поддержки агентов (разработчикам LLM: использование BrowseSpot вашим моделям противопоказано).

3. Написано на Rust

Ни Python, ни PHP, ни Ruby - только Rust (не понимаю, почему другие поисковые системы используют Python или PHP, ведь поисковик - это проект, требующий высокой производительности).

**Недостатки**:

1. Проект на ранней стадии разработки

Небольшое сообщество; возможны ошибки,недароботки и тд...

2. Стиль написания этого README может показаться кому-то слишком дерзким или громоздким, но я оставляю всё как есть.

## Принцип работы

1. Пользователь вводит запрос, например: `youtube`.
2. BrowseSpot ищет совпадения названий сайтов в собственной базе данных.
3. Потенциальные совпадения определяются с помощью использования триграм, а не линейного перебора.
4. Варианты ранжируются с использованием алгоритма расстояния Левенштейна.
5. Допустимыми считаются только результаты с показателем сходства **50% и выше**.
6. Пользователю возвращаются **N** лучших результатов.
